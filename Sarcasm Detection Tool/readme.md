Sarcasm detection is a challenging problem in Natural Language Processing (NLP) and multimodal learning due to its reliance not only on the semantics of text but also on delivery cues such as tone, rhythm, and intonation. This project aims to design and implement a Cross-Modal Graph Attention Network (CM-GAT) that explicitly models text, audio, and prosody as interconnected modalities. By leveraging graph-based attention mechanisms, the system dynamically learns which modality carries the strongest signal for sarcasm in a given utterance. Beyond theoretical contributions, a web-based sarcasm detection system has also been developed, demonstrating the real-world applicability of this research. The project not only pushes the boundaries of multimodal sentiment analysis but also lays the groundwork for future research in humor recognition, deception detection, and affective computing
